# sim-comfy2st (ComfyUI Drawer 极简黑箱生图插件)

专为 **SillyTavern（酒馆）** 与本地 **ComfyUI** 深度联动打造的极简黑箱化多场景/多分镜生图插件。

---

## 🌟 设计哲学与核心优势

1. **工作流黑箱化**：
   - 告别在酒馆前端繁复配置采样器、步数、CFG、模型等参数。
   - 无论你的 ComfyUI 工作流多么复杂（双阶段采样、高清修复放大、FaceDetailer、各种高级 Conditioning 等），只需在 ComfyUI 调试完成后导出 API JSON，插件即可无感黑箱调度。
2. **职责彻底分离（酒馆管词，ComfyUI 管图）**：
   - **ComfyUI 端**：使用通用底模与通用工作流，无需特化配置。
   - **酒馆端**：在角色卡中通过 `[SD_TAG: ...]` 绑定角色固有外观（发色、瞳色、服装等）；出图时由大模型依据上下文提取剧情中的动态动作与场景，二者智能组装为高质量提示词。
3. **关键接口智能绑定**：
   - 自动扫描工作流节点，提供可视化下拉映射：
     - 正向提示词节点（Prompt）
     - 负向提示词节点（Negative Prompt，可选）
     - 分辨率接管节点（Width / Height）
     - 随机种子同步节点（支持多选，同时同步一阶段与二阶段采样器 Seed）
4. **多场景预设与多分镜批出图**：
   - 支持自定义多套生图场景预设（如“默认单张情境”、“人物正背面2段分镜”、“面部特写”等）。
   - 支持大模型一次性生成多段分镜（使用 `---DIVIDER---` 分割），插件自动按序提交 ComfyUI 队列并组装为画廊连续展示。
5. **星标默认规则（★）与 AI 回复自动出图**：
   - 任意预设均可一键设为**默认激活预设（★）**。
   - 开启“AI 回复完成后自动出图”后，角色每次回复完毕，插件将全自动按照当前带星星标记的默认规则静默提取并下发生图，带来沉浸式图文互动体验。
6. **轻量、安全、防上下文膨胀**：
   - 图片生成后自动通过酒馆底层接口存为本地文件，杜绝百万 Token 的 Base64 污染大模型上下文。

## 📦 安装方法

### 方式一：酒馆扩展安装器（推荐）
1. 打开 SillyTavern，进入 **扩展菜单（Extensions Settings）** $\to$ **安装扩展（Install Extension）**。
2. 在 Git 仓库 URL 输入框中粘贴本仓库地址：
   ```text
   https://github.com/gl6963/sim-comfy2st.git
   ```
3. 点击安装并刷新页面即可。

### 方式二：手动克隆安装
进入 SillyTavern 安装目录下的第三方扩展文件夹并克隆：
```bash
cd public/scripts/extensions/third-party
git clone https://github.com/gl6963/sim-comfy2st.git comfyui-drawer
```
重新启动或刷新 SillyTavern 即可加载。

## 🚀 快速上手教程

### 第一步：在 ComfyUI 导出 API 格式工作流
1. 打开 ComfyUI 界面，点击设置图标（⚙️）。
2. 勾选 **`Enable Dev mode Options`（开启开发者模式）**。
3. 界面菜单中会出现 **`Save (API Format)`** 按钮。
4. 调试好你的生图工作流后，点击该按钮，保存得到 `workflow_api.json`。

### 第二步：在酒馆中配置工作流与接口
1. 打开 SillyTavern，点击右上角 **扩展设置（Extensions）** $\to$ **`ComfyUI 极简生图联动`** 面板。
2. 确认服务地址（默认为 `http://127.0.0.1:8188`），点击【测试连接】。
3. 将上一步保存的 `workflow_api.json` 拖入上传区。
4. 点击 **【智能匹配接口】**，检查正向词、负向词、分辨率和 Seed 节点绑定。
5. 点击底部的 **【保存所有设置】**。

### 第三步：在角色卡中绑定外观（可选推荐）
在角色的 **Description（描述）**、**Personality（性格）** 或 **世界书** 中加入如下标签格式：
```text
[SD_TAG: 1girl, solo, silver hair, blue eyes, white dress, masterpiece, best quality]
```

### 第四步：出图体验
- **方式 1**：在任意 AI 回复消息右上角的操作栏中，点击 **🎨 绘图图标** 快速出图。
- **方式 2**：在顶部魔棒快捷菜单中点击 **ComfyUI 生图**，打开独立预设面板自由选择不同分镜与预设出图。
- **方式 3**：在聊天输入框中使用斜杠指令：`/comfydraw` 或 `/comfy`。
- **方式 4（全自动插画）**：在预设列表中将喜欢的分镜规则设为 **默认激活（★）**，并勾选 **“AI 回复完成后自动出图”**。
